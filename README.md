# ML Biomedical Classification & Regression

## Overview
Machine learning project applying classification and regression pipelines 
to two biomedical datasets.

## Datasets
- **Clinical dataset** (270 patients): heart disease classification
- **Protein dataset** (45,730 observations): hydrophobic surface exposure regression (CASP)

## Methods
- Classification: Logistic Regression, LDA, QDA, KNN, Naive Bayes — best AUC: 0.922
- Regression: exhaustive/forward/backward selection, polynomial regression — best R²: 0.775
- Dimensionality reduction: PCA, t-SNE, UMAP

## Tools
Python, scikit-learn, statsmodels, pandas, numpy, matplotlib, seaborn
